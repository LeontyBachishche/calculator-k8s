# Распределенный микросервисный калькулятор в Kubernetes

Высокодоступное и отказоустойчивое веб-приложение для вычисления математических выражений, развернутое в кластере **Kubernetes (Minikube)**. Проект демонстрирует применение практик DevOps, безопасное управление секретами, асинхронную обработку задач, централизованное логирование и комплексный мониторинг.

## 🏗 Архитектура системы

Проект построен на базе микросервисной архитектуры и включает в себя следующие компоненты:

1. **Входной балансировщик (HAProxy)** — принимает внешний трафик на порту `30080` (NodePort) и балансирует HTTP-запросы между репликами веб-приложения по алгоритму Round-Robin.
2. **Фронтенд / Веб-приложение (Flask)** — легковесный веб-интерфейс. Проверяет наличие готового ответа в кэше, отправляет новые задачи в очередь и отдаёт метрики для Prometheus.
3. **Брокер сообщений (RabbitMQ)** — выступает в качестве буфера. Хранит асинхронную очередь задач `calc_tasks`, гарантируя доставку сообщений.
4. **Фоновый обработчик (Python Worker)** — изолированный сервис вычислений. Безопасно парсит выражения, кеширует результаты и инициирует запись в БД.
5. **Кэш (Redis)** — обеспечивает мгновенный доступ к ранее вычисленным выражениям (TTL кэша — 1 час).
6. **База данных (PostgreSQL)** — персистентное хранилище истории зарегистрированных пользователей и успешно выполненных вычислений с выделенным PV/PVC.
7. **Мониторинг (Prometheus & Grafana)** — сбор кастомных бизнес-метрики приложения и визуализация состояния кластера.
8. **Логирование (EFK Стек: Elasticsearch + Filebeat + Kibana)** — Filebeat в виде `DaemonSet` собирает системные логи контейнеров с ноды, отправляет их в Elasticsearch для индексации, а Kibana предоставляет интерфейс для их анализа.

### 🔄 Поток данных (Data Flow)
```text
Пользователь ➔ HAProxy ➔ Flask App ➔ [Проверка Redis (Кэш)]
                         ➔ (Если нет в кэше) ➔ Очередь RabbitMQ ➔ Python Worker ➔ [Вычисление] ➔ Запись в Redis & PostgreSQL
                                                                        │
                                                    [Системные логи] ➔ Filebeat ➔ Elasticsearch ➔ Kibana
```

## 🔒 Безопасность (Управление секретами)

Все конфиденциальные данные (пароли к базам данных и брокеру сообщений) полностью изолированы от исходного кода. 
* Внутри контейнеров параметры инициализируются динамически через переменные окружения `os.getenv()`.
* Внутри кластера Kubernetes значения безопасно поставляются из манифеста `Secret` (компонент `calc-secrets`).
* Файлы конфигурации секретов и локальные окружения внесены в `.gitignore` и защищены от утечки в публичный репозиторий.

## 🚀 Быстрый запуск в Minikube

### 1. Подготовка окружения и сборка образов
Включите движок BuildKit, переключите контекст терминала на Docker-демон внутри Minikube и соберите актуальные образы приложений:

**Для Windows (PowerShell):**
```powershell
# Включение современного движка сборки
\$env:DOCKER_BUILDKIT=1

# Активация окружения Minikube
minikube docker-env | Invoke-Expression

# Сборка компонентов
docker build -t calc-web-app:latest ./web-app
docker build -t calc-worker:latest ./worker
```

**Для Linux / macOS (Bash):**
```bash
export DOCKER_BUILDKIT=1
eval \$(minikube docker-env)
docker build -t calc-web-app:latest ./web-app
docker build -t calc-worker:latest ./worker
```

### 2. Развертывание инфраструктуры и секретов

1. Закодируйте ваши пароли в формат Base64 в зависимости от вашей ОС:

   **Для Windows (PowerShell):**
   ```powershell
   # Кодируем строку "my_password" в Base64
   [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes("my_password"))
   ```

   **Для Linux / macOS (Bash):**
   ```bash
   echo -n 'my_password' | base64
   ```

2. Создайте файл `k8s/secrets.yaml` на основе вашего шаблона секретов, подставив полученные Base64-строки.
3. Примените все конфигурации одной командой из корня проекта:
   ```bash
   kubectl apply -f ./k8s/
   ```

### 🔗 Ссылки для доступа к сервисам в браузере

Если вы используете Minikube на Windows с Docker-драйвером, для получения прямой ссылки на любой веб-интерфейс запустите команду туннелирования:
```powershell
minikube service <имя-сервиса> --url
```

В общем случае (при использовании виртуальных машин) доступ осуществляется по IP-адресу кластера (`minikube ip`):

* 🧮 **Калькулятор (через HAProxy):** `http://<MINIKUBE_IP>:30080`
* 📊 **Grafana Дашборды:** `http://<MINIKUBE_IP>:30030`
* 🔥 **Prometheus Метрики:** `http://<MINIKUBE_IP>:30090`
* 🪵 **Kibana (Логи ELK):** `http://<MINIKUBE_IP>:30161`
* 🐰 **RabbitMQ Управление:** `http://<MINIKUBE_IP>:31672`
* 🔍 **Elasticsearch API:** `http://<MINIKUBE_IP>:30200`

💡 **Подсказка:** Список всех запущенных веб-интерфейсов и автоматическое открытие ссылок на них можно сделать одной командой:
```powershell
minikube service --all
```
